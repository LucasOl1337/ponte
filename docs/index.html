Your tailnet, not a vendor cloud

The phone talks to your PC over Tailscale TLS. A device on the same account pairs without a password. Ponte has no analytics SDK.

The monitor is the UI

Tap clicks. Long-press right-clicks or drags. Pinch zooms. Two fingers scroll. Tap a text field and the Android keyboard types on the PC.

Omarchy-shaped controls

Workspaces, RGB lights, lock, suspend, terminals that do not steal the PC's focus. Built for this desktop, not a generic remote-desktop clone.

How it works

A Node server on your Omarchy PC. An Android shell that pins your certificate. HTTP stays on loopback.

01

Build for your PC

Setup writes a local config and certificate. The APK pins that leaf. Somebody else's APK will not talk to your machine.

02

Same Tailscale account

Open the app. If the phone is on your tailnet, it connects on its own. No pairing key to type.

03

Touch the monitor

Screen is the first page. The stream is authenticated MJPEG. It stops when you leave.

04

Keep it private

A paired phone is physical access. Tailscale membership stays your job. Read the security model before you add a second device.

The running app

Home: the PC is already there

Hostname, windows, workspaces, the focused app. Pick a monitor and a quality profile, then open the screen. English is the default; Portuguese sticks once you choose it.

Screen: live monitor, direct touch

The monitor fills the phone. Sharp streams native pixels at up to 15 fps. There is no system audio. This is for control and checking progress, not gaming.

  • Verified live frames on a Redmi Note 13 Pro+ (Android 14), 5 September 2026
  • A local three-monitor sample measured 7.11–7.33 fps and 78–177 ms to the first frame

Terminals: type without stealing focus

Private tmux sessions for the phone. Send runs the command. Speak drops a transcript into the composer. The PC's focused window stays put.

Windows: one tap to the next focus

Browse workspaces and open windows, then focus the one you want. The list is the live Hyprland client list of the demo instance.

Power, lights, session

Per-monitor DPMS, smart sleep, RGB presets through Magma, lock, suspend, restart. Unlock types the password on the PC only while the Omarchy lock is up. It is never stored on the phone.

Voice: record here, play there

Record on the phone, review, send. Files live on your PC. Dictation uses Sussurro when it is running, or any OpenAI-compatible endpoint. Audio is transcribed and discarded. Android recording on a physical device is still pending retest.

Set it up

Omarchy/Hyprland, Node 22+, Python 3.12+, OpenSSL 3, Tailscale on both devices. You need hyprctl, ydotool, wtype, grim, wpctl, ffmpeg, tmux.

# from a graphical session, not a headless SSH
git clone https://github.com/LucasOl1337/ponte.git
cd ponte
./ponte setup
./ponte install
./android/build.sh

# then install .work/Ponte.apk on your phone, privately

The APK contains your server address and public certificate. Do not redistribute it. Full paths, TLS renewal and troubleshooting: setup guide. Tested scope: evidence.
