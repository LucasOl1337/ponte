# Ponte v0.1.0-alpha.19 — keyboard, touch and connection recovery

19 September 2026. This alpha gathers the local updates since alpha.13: review text before sending it, use workspace controls from the streamed screen, and diagnose connection problems.

## Improvements

- **Send a complete line:** the phone keeps text locally until Send, then types it and presses Enter in one server action. Send without Enter pastes; failed sends keep the draft.
- **Keyboard layout:** the typing field retains focus while the Android keyboard opens; the bar stays above it in portrait and landscape.
- **Screen gestures:** ordinary movement tolerance preserves taps, one-finger dragging selects or drags content, and long-press dragging holds Super to move windows. The workspace shelf remains available as a drop target.
- **Workspace controls:** the screen displays occupied and active workspaces and follows the corresponding monitor when switching.
- **Adaptive stream quality:** Auto steps image quality up or down according to frame delivery and backs off after connection trouble. The transport remains MJPEG.

## Fixes

- Pointer placement checks the actual cursor position and compensates for virtual-device acceleration; persistent inaccuracy is reported.
- Auto-pairing retries failed Tailscale owner discovery instead of staying unavailable until restart.
- Android retries failed initial page loads and recovers after backgrounding.
- Server crashes no longer cycle the input daemon; invalid configuration or TLS prevents startup before application state is initialized.

## Operations and upgrade

- Installation CA pinning allows renewal of the server certificate under that CA. The app explains certificate mismatch separately from reachability errors. Existing APKs pinned to an earlier certificate may require rebuilding against the installation CA.
- `ponte doctor` inspects services, certificates, connectivity, pairing and APK version. Phone commands manage the owner's configured adb connection over Tailscale.
- An isolated lab supplies fake desktop tools and a synthetic screen for gesture testing.

Source distribution only: build the Android app against your own installation CA using the [setup guide](https://github.com/LucasOl1337/ponte/blob/v0.1.0-alpha.19/docs/setup.md). No private configuration, signing keys or personalized APK is included.

Validation in this publication: 133 Node tests passed, 1 opt-in systemd test skipped; 270 native checks and 7 configuration tests passed; a synthetic signed APK was built and checked for accidental inclusion of private keys or configuration. Real phone and desktop interaction were not repeated in this round. Experimental alpha.
